# Cycle Social Network

Социальная сеть нового поколения, написанная на Vanilla JavaScript и Node.js.

## 🚀 Как запустить проект

У проекта есть два режима запуска: для удобной разработки (соло) и для показа друзьям (через интернет).

### 1. Режим соло-разработки (Локально / Офлайн)
Используй этот режим, когда сам пишешь код. Он работает мгновенно, не требует интернета и сам перезагружает сервер при сохранении файлов бэкенда.

1. Открой терминал в корне проекта.
2. Введи команду:
   \`\`\`bash
   npm run dev
   \`\`\`
3. Открой в браузере ссылку: **http://localhost:3000**

*(Если меняешь файлы в папке `public`, сервер перезапускать не нужно — просто нажми `Ctrl + F5` в браузере, чтобы сбросить кэш).*

---

### 2. Режим для друзей (Онлайн)
Используй этот режим, если хочешь скинуть ссылку на работающий сайт друзьям. Сервер запустит туннель (LocalTunnel) и выдаст публичную ссылку.

1. Останови текущий сервер, если он запущен (`Ctrl + C` в терминале).
2. Введи команду:
   \`\`\`bash
   npm run share
   \`\`\`
3. В терминале появится ссылка вида `https://random-words.loca.lt`. Отправь её друзьям.

**⚠️ ВАЖНО: Пароль для LocalTunnel**
Когда друзья перейдут по ссылке, сайт может попросить ввести **Tunnel Password**. 
В качестве пароля нужно ввести внешний IP-адрес того, кто переходит по ссылке.
* Как узнать свой IP: просто зайти на сайт [https://ipv4.icanhazip.com](https://ipv4.icanhazip.com)
* Скопировать цифры и вставить в окно защиты LocalTunnel.

## 📂 Структура проекта

* `/public` — Фронтенд (всё, что видит браузер: HTML, CSS, JS, картинки, музыка).
* `/server` — Бэкенд (Node.js, логика, API, работа с базой).
  * `/server/db/cycle.db` — База данных SQLite.
* `/uploads` — Загруженные пользователями файлы (аватары, музыка, голосовые сообщения).
